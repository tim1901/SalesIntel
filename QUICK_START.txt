STEPS TO UPLOAD & DEPLOY (30 MINUTES)
================================================================================

STEP 1: Update API Key (2 min)
----
1. Open .env.local
2. Replace: sk-ant-v7_your_api_key_here
3. With: Your actual key from https://console.anthropic.com/api_keys

STEP 2: Create GitHub Repo (2 min)
----
1. Go to https://github.com/new
2. Name: SalesIntel
3. Public
4. Create

STEP 3: Upload to GitHub (5 min)
----
Open terminal in bd-agent folder, run:

git init
git add .
git commit -m "Initial commit: B2B Sales Intelligence Agent"
git remote add origin https://github.com/YOUR_USERNAME/SalesIntel.git
git branch -M main
git push -u origin main

(Replace YOUR_USERNAME with your GitHub username)

STEP 4: Deploy to Netlify (3 min)
----
1. Go to https://app.netlify.com
2. Click "Add new site"
3. Select "Import an existing project"
4. Choose "GitHub"
5. Authorize and select SalesIntel
6. Click Deploy

STEP 5: Add API Key to Netlify (2 min)
----
1. Wait for initial build (2-3 min)
2. Site Settings → Build & Deploy → Environment
3. Add variable:
   Key: ANTHROPIC_API_KEY
   Value: sk-ant-v7_your_actual_key
4. Save

STEP 6: Redeploy (3 min)
----
1. Go to Deploys
2. Click "Trigger deploy"
3. Wait 2-3 minutes

STEP 7: Test (5 min)
----
1. Click Netlify URL
2. Enter company name (try "Google")
3. Click Research
4. Wait 2-3 minutes
5. Click an executive
6. Generate email
7. Done!
